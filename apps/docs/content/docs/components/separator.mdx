**Vinyl styling:** Uses the border token.

## Installation

```bash
npx shadcn@latest add @vinyl/separator
```

The `@vinyl` registry URL in `components.json` decides whether you get the web or the native version (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## API

Same API as shadcn/ui's [Separator](https://ui.shadcn.com/docs/components/separator) on the web, and React Native Reusables' [Separator](https://reactnativereusables.com/docs/components/separator) on native. Vinyl only changes styling and motion.
