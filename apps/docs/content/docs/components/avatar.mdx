**Vinyl styling:** Square geometric frame; the fallback uses the sunset gradient (magenta on native).

## Installation

```bash
npx shadcn@latest add @vinyl/avatar
```

The `@vinyl` registry URL in `components.json` decides whether you get the web or the native version (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## Usage

<Tabs items={['Web', 'React Native']}>
<Tab value="Web">

```tsx
<Avatar>
  <AvatarImage src="/dj.jpg" alt="DJ Nova" />
  <AvatarFallback>DJ</AvatarFallback>
</Avatar>
```

</Tab>
<Tab value="React Native">

```tsx
<Avatar alt="DJ Nova">
  <AvatarImage source={{ uri: 'https://…/dj.jpg' }} />
  <AvatarFallback><Text>DJ</Text></AvatarFallback>
</Avatar>
```

</Tab>
</Tabs>

## API

Same API as shadcn/ui's [Avatar](https://ui.shadcn.com/docs/components/avatar) on the web, and React Native Reusables' [Avatar](https://reactnativereusables.com/docs/components/avatar) on native. Vinyl only changes styling and motion.
