## Installation

```bash
npx shadcn@latest add @vinyl/neon-tile
```

Works on both platforms; the `@vinyl` registry URL decides which version you get (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## Usage

<Tabs items={['Web', 'React Native']}>

</Tab>

## API

| Prop | Values | Default |
| --- | --- | --- |
| `size` | `sm` (48px) `md` (80px) `lg` (128px) | `md` |
| `shine` | Periodic [Shine](/docs/effects/shine) sweep | `true` |

Content is centred in heavy italic `night`, so use a letter, icon or your own mark. On native the gradient is drawn with `react-native-svg`, and the rim glow is an iOS shadow.
