**Vinyl styling:** Small display caps with wide tracking.

## Installation

```bash
npx shadcn@latest add @vinyl/label
```

The `@vinyl` registry URL in `components.json` decides whether you get the web or the native version (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## Usage

<Tabs items={['Web', 'React Native']}>
<Tab value="Web">

```tsx
<Label htmlFor="callsign">Callsign</Label>
<Input id="callsign" />
```

</Tab>
<Tab value="React Native">

```tsx
<Label nativeID="callsign">Callsign</Label>
<Input aria-labelledby="callsign" />
```

</Tab>
</Tabs>

## API

Same API as shadcn/ui's [Label](https://ui.shadcn.com/docs/components/label) on the web, and React Native Reusables' [Label](https://reactnativereusables.com/docs/components/label) on native. Vinyl only changes styling and motion.
