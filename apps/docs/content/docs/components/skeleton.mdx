**Vinyl styling:** Pulsing muted block with CRT scanlines on web.

## Installation

```bash
npx shadcn@latest add @vinyl/skeleton
```

The `@vinyl` registry URL in `components.json` decides whether you get the web or the native version (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## API

Same API as shadcn/ui's [Skeleton](https://ui.shadcn.com/docs/components/skeleton) on the web, and React Native Reusables' [Skeleton](https://reactnativereusables.com/docs/components/skeleton) on native. Vinyl only changes styling and motion.
