<Preview name="tooltip" />

**Vinyl styling:** Night-black chip with a magenta rim and VT323 type; bar-wipes in.

## Installation

```bash
npx shadcn@latest add @vinyl/tooltip
```

The `@vinyl` registry URL in `components.json` decides whether you get the web or the native version (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## Usage

<Tabs items={['Web', 'React Native']}>
<Tab value="Web">

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild><Button variant="outline">Hover me</Button></TooltipTrigger>
    <TooltipContent>Press PLAY to start</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

</Tab>
<Tab value="React Native">

```tsx
<Tooltip>
  <TooltipTrigger asChild><Button variant="outline"><Text>Press me</Text></Button></TooltipTrigger>
  <TooltipContent><Text>Press PLAY to start</Text></TooltipContent>
</Tooltip>
```

</Tab>
</Tabs>

## API

Same API as shadcn/ui's [Tooltip](https://ui.shadcn.com/docs/components/tooltip) on the web, and React Native Reusables' [Tooltip](https://reactnativereusables.com/docs/components/tooltip) on native. Vinyl only changes styling and motion.
