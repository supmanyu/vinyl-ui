## API

Renders SMPTE ECR 1-1978 bars at 16:9 with `role="img"`. The overlay text (`children`) is also used as the accessible label. Otherwise `label` is used (default "Test pattern"). Pair it with `SmpteWipe` for a channel-change reveal.
