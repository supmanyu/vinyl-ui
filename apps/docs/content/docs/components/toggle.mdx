**Vinyl styling:** Pressed state uses the cyan secondary colour.

## Installation

```bash
npx shadcn@latest add @vinyl/toggle
```

The `@vinyl` registry URL in `components.json` decides whether you get the web or the native version (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## Usage

<Tabs items={['Web', 'React Native']}>
<Tab value="Web">

```tsx
<Toggle variant="outline" aria-label="Loop">Loop</Toggle>
```

</Tab>
<Tab value="React Native">

```tsx
<Toggle pressed={loop} onPressedChange={setLoop} variant="outline" aria-label="Loop">
  <Text>Loop</Text>
</Toggle>
```

</Tab>
</Tabs>

## API

Same API as shadcn/ui's [Toggle](https://ui.shadcn.com/docs/components/toggle) on the web, and React Native Reusables' [Toggle](https://reactnativereusables.com/docs/components/toggle) on native. Vinyl only changes styling and motion.
