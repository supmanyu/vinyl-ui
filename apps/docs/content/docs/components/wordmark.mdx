## Installation

```bash
npx shadcn@latest add @vinyl/wordmark
```

Works on both platforms; the `@vinyl` registry URL decides which version you get (see installation for [web](/docs/installation/web) / [native](/docs/installation/native)).

## Usage

<Tabs items={['Web', 'React Native']}>
<Tab value="Web">

```tsx
import { StripeText } from '@vinyl-ui/effects';
import { Wordmark } from '@/components/ui/wordmark';

<Wordmark size="lg" lines={['Night', 'Drive', 'Radio']} accent={<StripeText>86</StripeText>} />
```

</Tab>
<Tab value="React Native">

```tsx
import { StripeText } from '@vinyl-ui/effects';
import { Wordmark } from '@/components/ui/wordmark';

<Wordmark

```

</Tab>

## API

| Prop | Values | Default |
| --- | --- | --- |
| `lines` | `string[]`: one per row; colours cycle yellow → magenta → blue | — |
| `accent` | Node beside the stack (scaled to 2.6em on web) | — |
| `size` | `sm` `md` `lg` | `md` |

Renders a single heading whose accessible name is the lines joined with spaces. The decorative accent is hidden from assistive tech.
